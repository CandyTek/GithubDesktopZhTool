# GitHub Desktop 汉化工具（Windows）

GitHub Desktop 更新后，部分界面的汉化可能会失效。本项目旨在简化重新汉化的步骤：无需每次前往上游仓库手动下载最新汉化包，只需双击 `update.cmd`，即可自动获取最新资源并打开汉化工具，再按界面提示完成汉化。

本仓库仅面向 **Windows 平台**，提供 GitHub Desktop 汉化资源及一键更新脚本。汉化资源同步自上游 `robotze/GithubDesktopZhTool`，请确认汉化工具支持的版本与你安装的 GitHub Desktop 版本一致。

## 使用方法

1. 安装 Git，并将其加入 PATH
2. 以下任选一种获取方法：
 - 直接下载仓库`update.cmd`并放在一个**空文件夹**
 - 在仓库页面选择 **Code → Download ZIP**，将 ZIP 解压到一个独立文件夹
 - 使用任意 Git 工具克隆本仓库
3. **双击 `update.cmd` 即可更新并启动汉化工具**，然后按工具界面提示完成汉化。

脚本会自动同步远端当前分支的最新内容，使用仓库附带的 7z 解压汉化工具，并启动 `GithubDesktopZhTool.exe`。关闭工具后，脚本会删除解压出来的临时工具文件夹。

通过 ZIP 下载时，首次运行会自动在脚本所在目录创建 `.git`，配置本仓库为远端，并浅拉取 `main` 分支。之后直接双击同一个 `update.cmd` 即可继续更新。请先解压 ZIP，再运行脚本。

**注意：更新会丢弃仓库内的本地修改，并删除未跟踪及被忽略的文件。请勿在仓库文件夹中存放个人文件。**

## 7z 解压组件

仓库附带 `7z.exe` 和 `7z.dll`，用于解压汉化工具的 `.7z` 压缩包，因此无需单独安装 7-Zip。

这两个文件取自 **Lua 5.1 运行时程序**，在此作为解压组件使用；运行更新脚本无需安装 Lua。以下 MD5 值对应本仓库当前附带的文件，可用于核对文件是否一致：

| 文件 | MD5 |
| --- | --- |
| `7z.exe` | `27FDC440E9D9DE4DBE710E9C1226B72D` |
| `7z.dll` | `81E1639A96FAC1C92CAF6427EB94BFA7` |

可以在仓库目录中通过 PowerShell 核对：

```powershell
Get-FileHash .\7z.exe, .\7z.dll -Algorithm MD5
```

## 自动同步

工作流每天自动检查上游，也支持手动运行。每次同步只获取最新快照，并将 `main` 分支历史压缩为一个无父提交的根提交。

每次同步还会删除本仓库远端的所有标签（Tags），避免旧标签继续引用历史版本，导致普通克隆下载旧历史。即使文件内容没有变化，也会执行标签清理；本仓库不保留版本标签。

同步时保留本仓库的工作流、`README.md`、`update.cmd`、`7z.exe` 和 `7z.dll`，避免被上游文件覆盖。
